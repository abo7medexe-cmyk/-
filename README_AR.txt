مشروع منبّه الأذان لبناء APK عبر GitHub Actions

الخطوات:
1. فك ضغط الملف على الهاتف.
2. إذا كان لديك ملف الخط NotoNaskhArabic-VariableFont_wght.ttf، ضعه بجانب main.py.
3. ارفع كل محتويات هذا المجلد إلى مستودع GitHub جديد، مع إظهار الملفات المخفية لكي يُرفع مجلد .github.
4. اسم المستودع/الفرع يجب أن يكون main.
5. افتح تبويب Actions في المستودع. وافق على تفعيل Actions إذا طُلب منك.
6. انتظر انتهاء سير العمل Build منبّه الأذان APK.
7. افتح نتيجة التشغيل الناجح ونزّل Artifact باسم AdhanAlarm-debug-apk. فك ضغط artifact لتحصل على APK.

إذا لم يبدأ البناء تلقائيًا، من Actions افتح Build منبّه الأذان APK ثم Run workflow.

مهم:
- ملف الخط لم يُضمّن لأن المستخدم ذكر اسمه فقط ولم يرفع الملف نفسه.
- هذه نسخة اختبارية لعرض مواقيت الصلاة، وليست بعد نسخة تضمن الأذان في الخلفية أو بعد إعادة تشغيل الهاتف.
- أول بناء قد يستغرق وقتًا لأنه ينزّل Android SDK وNDK.
